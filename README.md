# Customer Behavior Analysis

## Internship Project

This project was completed as part of my Data Analytics Internship.

## Objective

The objective of this project is to analyze customer purchasing behavior and identify customer segments using RFM Analysis.

## Dataset

- Source: Kaggle
- Total Records: 250,000
- Customers: Approximately 50,000

## Tools Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow

1. Data Cleaning
2. Feature Engineering
3. Exploratory Data Analysis
4. Customer Segmentation (RFM)
5. Business Recommendations

## Key Insights

- Identified high-value customers using RFM Analysis.
- Analyzed purchasing trends across product categories.
- Studied payment method preferences.
- Identified customer segments for targeted marketing.
